The manual’s Markdown, offline HTML and tagged printable PDF are generated from one source. Earlier originals are preserved under the before-fixes capture directory; updated PNGs, separate numbered overlays and compositions use the reliability capture directory. The guide build checks offline decoding, anchors and 390px overflow; PDF page-bound/caption checks are recorded separately.

External verification constraints: Windows execution/installers, real microphone speech/mute/disconnect, audible playback and actual Whisper recognition cannot be verified with this Linux synthetic-input environment. OpenRouter credentials and paid execution were deliberately unused. Publishing, OCR, AI search and recovery after forced process termination remain outside scope.

Final checks: 96 tests across 19 files, type checking, lint, formatting, build, and 17 isolated Linux Electron workflow observations passed. Windows path semantics are unit-tested; Windows execution remains unverified.
