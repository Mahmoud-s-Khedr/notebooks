## Checks and limitations

Release checks passed: all 122 tests across 21 unit/service/renderer/preload files; type checking; lint with zero warnings; formatting; production build; and the illustrated guide build. The guide has 55 figures, no broken images or missing anchors, no external resources and no overflow at 390 pixels. Formatting excludes the supplied acceptance artifacts so they remain unchanged. Live results are in [repair-workflow-verification.json](repair-workflow-verification.json); screenshots are in `docs/images/repairs/`. The app was run with an isolated disposable library and Chromium synthetic microphone. The supplied archive exercised all four formats at notebook, page and note scopes.

Native Windows import/application behavior, physical microphones, fresh Egyptian Arabic recognition, packaged Linux/Windows sidecars and assistive-technology PDF inspection remain unavailable. `npm run verify:sidecars` fails because `resources/whisper.cpp/checksums.json` and the bundled runtimes are absent; packaging is deliberately blocked by that existing release check. No platform check is marked passed by inference. OCR and VAD are future work, as described in [options](extraction-and-transcription-options.md).

The initial large-library benchmark terminated while preparing its fourth fixture and emitted no report. The follow-up used bulk SQLite block insertion outside measured samples to avoid repeated search-index rebuilds during fixture construction; notes/assets still use public APIs and the index is refreshed before measurement. It completed five samples in each of five scenarios on the same Linux machine. [Raw results](performance-repairs.json) and [comparison](performance-repair-comparison.json) show no measured median above the existing 25% regression budget against the retained October 5 baseline. This is one development-machine comparison, with synthetic audio and different fixture preparation; it does not establish production latency or general performance. Historical reports remain unchanged.

After integrating upstream commit `a092b71`, transcript review saves cache the returned correction before run switching. Regression tests cover returning to both original and previously reviewed runs, repeated corrections, and retry after a failed save. The integrated tree passes all 130 tests across 22 files, type checking, lint, and the production build.
